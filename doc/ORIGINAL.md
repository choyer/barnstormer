# Relationship to the original Sopwith

This is a re-implementation, not a port. Every line of C in `game/`,
`render/`, `platform/`, `audio/` and `main.c` was written for this project in
2026. What it does reproduce, deliberately and closely, is the *behaviour* of
the 1984 game, because a Sopwith that flies differently is not Sopwith.

The original sources are in `../origsrc`, released by David L. Clark under the
licence reproduced in `../src/LICENSE.origsopwith.txt`. That licence permits
modified versions provided the copyright notice stays on screen, the licence
travels with the code, and modified files say that they were modified. This
file is the statement of what changed; all changes date from 2026-09.

## Taken from the original

| What | Where it came from | Where it lives now |
|---|---|---|
| Terrain height field (3000 columns) | `SWGROUND.C` | `data/level_classic.c` |
| Runway and building layout | `SWGAMES.C` | `data/level_classic.c` |
| Ox and bird-flock spawns | `SWINIT.C` | `data/level_classic.c` |
| All sprite artwork | `SWPLANES.C`, `SWSYMBOL.C` | `data/sprites.c` |
| Flight model, stall and fall behaviour | `SWMOVE.C` | `game/move.c` |
| Fixed-point motion (16.16, carry into pixels) | `SWUTIL.ASM` | `game/objects.c` |
| Collision rules and the kill table | `SWCOLLSN.C` | `game/collision.c` |
| Autopilot, gunnery prediction, homing | `SWAUTO.C` | `game/autopilot.c` |
| Spawning, ordnance, scoring, difficulty | `SWINIT.C` | `game/game.c` |
| Sound priorities, tones and the explosion tune | `SWSOUND.C` | `game/sound.c` |
| Key assignments | `SWUTIL.ASM` scan tables | `platform/wl_backend.c` |

The data files are regenerated by `make regen-data`, which runs the two
extractors in `tools/`. Nothing is transcribed by hand, so the artwork and
terrain are bit-identical to the 1984 originals.

## Deliberate differences

**Presentation.** The original drew XOR sprites into CGA video memory and drew
the landscape as a one-pixel outline. Here the landscape is a filled solid and
sprites can be filled too (`render/sprites_solid.c` floods each frame's
enclosed regions), because outlines vanish against a desktop wallpaper. The
head-up display is a redesign of the original's bottom-of-screen gauge strip
with the same information: fuel, ammunition, bombs, missiles, flares, lives,
score, difficulty, buildings remaining, and the compressed map.

**Timing.** The original advanced the world when a counter driven by the
18.2 Hz PC timer passed a threshold, which worked out at 12.14 moves a second.
That rate is preserved exactly (`GAME_TICK_HZ`); the display refreshes
independently at whatever rate the compositor allows.

**Sound.** Tones are still described as 8253 timer divisors, and the explosion
tune is still parsed from the original's note strings, but they are synthesised
as square waves and pushed to ALSA rather than to a speaker cone.

**Bug fixes.** Three places in the original read outside their arrays. A stray
bird could wander off the end of the map and index the terrain array out of
bounds; here it turns back at the edge. `tstcrash()` in the autopilot iterated
from index -1 when no buildings were nearby; here that case iterates zero
times. `initshot()` tested an uninitialised pointer to decide whether the
shooter had ammunition; here the test is on the shooter, which restores the
evident intent (only human pilots run dry).

**Dropped.** The Imaginet and serial-line two-player modes, the DOS history
recorder, the joystick, and the PCjr/Atari ST variants. The
"you flew into an ox" full-screen splat was present in the original sources but
never called; it is wired up here because it is too good a joke to lose.

**Play modes.** Novice, single player and single-player-against-the-computer
are the original's `-n`, `-s` and `-c`. Networked play is designed for
(`include/net.h`) but not implemented.
